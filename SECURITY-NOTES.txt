[SUPABASE]
- 브라우저 코드에는 Publishable/anon 용도의 공개 키만 사용합니다.
- Secret key / service_role key / DB 비밀번호 / 개인 access token을 브라우저 코드나 Git 저장소에 넣지 않습니다.
- 실제 데이터 보호는 RLS, RPC 권한, SECURITY DEFINER 함수, Storage policy를 포함해 서버 측에서 검증해야 합니다.
- 프론트엔드 저장소만으로 RLS/RPC/Storage 정책의 안전성을 확정하지 않습니다.
