DELETE CUSTOMER

실제 데이터는 영구 삭제하지 않습니다. 기존 CHECK · CARE · REPORT 기록은 그대로 보존됩니다.

PERMANENT DELETE

고객 데이터를 영구 삭제하시겠어요?

—

이 작업은 복구할 수 없습니다. CARE 사진의 Storage 파일까지 먼저 삭제한 뒤 고객과 연결된 데이터를 DB에서 영구 삭제합니다.

위 고객의 이름을 정확히 입력해야 영구 삭제할 수 있습니다.
