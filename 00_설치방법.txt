[Supabase 설정]
assets/js/supabase-config.js 에서 프로젝트의 공개용 연결 정보를 사용합니다.

중요:
- Publishable/anon 용도의 공개 키만 브라우저 코드에서 사용합니다.
- Secret key / service_role key / DB 비밀번호 / 개인 access token은 절대 저장소에 커밋하지 않습니다.

[현재 주요 기능]
- Supabase Auth 기반 관리자 로그인/세션
- admin_profiles 기반 관리자 권한 확인
- 관리자 대시보드 및 고객 상세
- 무료 CHECK/진단 흐름
- 예약 관련 흐름
- CARE 방문/기록 관련 관리자 기능
- CARE REPORT 관련 공개/관리 흐름

[배포]
GitHub Desktop에서 변경사항을 검토한 뒤 Commit → Push 합니다.
CNAME 파일은 삭제하지 않습니다.

[코드 관리 원칙]
- 현재 UI/기능 결과를 확인하지 않고 레거시 코드를 삭제하지 않습니다.
- HTML → CSS → JavaScript → 동적 class/id → asset → API/RPC 의존성을 확인합니다.
- 데이터 손실 가능성이 있는 DB/RPC/RLS/Storage 변경은 별도 검증 후 진행합니다.
- 텍스트 파일 줄바꿈 정책은 .gitattributes 기준을 따릅니다.
- 로컬 CSS/JS cache-busting 버전은 페이지 간 동일 규칙으로 관리합니다.
