[어디에 넣나요?]
현재 실제 사이트 폴더:
moohae-site > moohae

이 압축파일 안의 admin 폴더와 assets 폴더를
moohae 폴더 안에 그대로 넣거나 덮어쓰면 됩니다.

[가장 중요한 설정 1개]
assets/js/supabase-config.js 를 열고 아래 두 값만 교체하세요.

YOUR_SUPABASE_URL
→ Supabase Data API 화면에서 복사한 API URL

YOUR_SUPABASE_PUBLISHABLE_KEY
→ Settings > API Keys 의 Publishable key

주의:
Secret key / service_role key는 절대 입력하지 마세요.
